# Tactical Search — 수색을 Gameplay로 만들기

## 설계 의도

컨테이너를 여는 행위를 ‘즉시 보상 수령’으로 끝내지 않습니다. 플레이어는 수색 중에도 주변 전투와 안전을 판단해야 합니다.

```text
컨테이너 접근
→ Search 시작
→ 아이템 순차 Reveal
→ 위험 감지 시 중단 또는 계속
→ 발견물 선택·운반
```

## 핵심 규칙

- 컨테이너는 위치와 종류에 따른 Loot/Search Identity를 가질 수 있습니다.
- 발견 시간은 아이템의 난도와 컨테이너 조건으로 달라집니다.
- 이동, 사격, 피격, 명시적 취소는 Search를 중단할 수 있습니다.
- 이미 Reveal된 항목은 다시 숨지 않으며, 재접근 시 남은 항목부터 이어집니다.
- 중단과 재개는 보상 reroll 수단이 될 수 없습니다.

## 왜 위험이 중요한가

수색 중 ‘방 안을 더 확인할까, 문 밖의 적부터 처리할까’가 생깁니다. 따라서 좋은 Loot는 단순 희귀도 표기가 아니라 노출 시간, 위치, 가방 공간, 귀환 거리와 결합한 실제 선택이 됩니다.

## Police Station 수직 슬라이스

현재 검증 공간에서는 Room/Container, Loot Reveal, Loose Loot, Backpack, 전투 공간이 함께 이어집니다. 이 문서는 구체적인 맵 데이터나 내부 테스트 자산을 담지 않으며, 수색 행동이 어떤 루프와 연결되는지만 공개합니다.
